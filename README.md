# Image-Super-Resolution

## Project Overview
The objective is to build a robust Multi-Scale Deep Super-Resolution network capable of upscaling low-resolution images by factors of x2, x3, and x4. The architecture utilizes a shared feature extraction trunk that branches into scale-specific upsampling tracks to ensure efficient multi-scale learning and real-world generalizability.
